第1步 · 先确定整篇要说什么

先说一句最重要的话

今天的地点：天安门广场。
今天的终点：完成一篇有开头、两条不同理由和结尾的周作文口述稿。
如果没去过的同学最后只能记住一件事，你最想让他记住天安门广场的什么？

先等孩子自己说。停住时只提醒：“你最想带同学看什么？”

第2步 · 打开昨天的素材盒

选两条不同的线

这些只是昨天口述和资料里出现过的材料，不是必须使用的答案。先选最想讲、最能讲清楚的两项。

现场能看到或听到的

体验线

能让人多知道一些的

认识线
已经选择 0 / 2 项

写之前先守住三条事实

  • 如果自己没有亲眼看过升旗，就说“我想去看”或“我从资料中看到”，不写成亲身经历。
  • 升旗时间随日期变化，不写固定的“凌晨两点、三点或五点”。
  • 今天写天安门广场，不把神武门、太和殿等故宫内容混进来。
卡住时再打开：怎样判断两条线不同

一条可以回答“到了现场，我能看到、听到什么”；另一条可以回答“我会多知道、想明白什么”。如果两条都只是在列景物，重新换一项。

第3步 · 展开第一条理由

先把一条线说清楚

第一条线

一次只说当前这一格。家长记录原话，不在孩子说话时润色。

1. 这一段主要推荐什么？
2. 到了那里，人能看到、听到或做什么？
3. 哪两三个细节最能让人看见这个画面？
4. 这些细节让游客得到什么？
5. 为什么这一点值得推荐？
6. 合上前五格，把这一段连起来说
卡住时再打开：看一座异主题的桥
图书馆有主题书架
读者能快速找到书
会得到新知识
所以适合喜欢阅读的人

只看每格在做什么，不把图书馆内容搬到天安门。

第4步 · 展开第二条理由

换一个角度，再说一段

第二条线

第二段不能只是换一个景物名称。它要让读者得到与上一段不同的体验或认识。

1. 这一段主要推荐什么？
2. 到了那里，人能看到、听到或了解到什么？
3. 哪两三个细节能支持这一段？
4. 这些材料让游客多知道或想明白什么？
5. 为什么这一点也值得推荐？
6. 合上前五格，把这一段连起来说
卡住时再打开：只缩小当前问题

先选一种：这一段主要让同学“看到一幅画面”，还是“知道一段历史或作用”？只选类别，具体内容仍由你自己说。

第5步 · 只加工一句话

让直白句变得能看见

顺序：写什么 → 它真实是什么样或怎样变化 → 选准确词 → 再决定要不要比喻。

先补真实特征

它的动作、声音、光线、颜色、位置或变化到底是什么？

再选一个有依据的词

缓缓整齐肃静宽阔矗立清晰映照回荡

不合事实的词不要用。每段一两个准确词就够了。

如果比喻说不清共同点，直接准确描写比硬写“像什么”更好。说好以后，回到对应段落的第6格，把原来的直白句换成这句；最终整理稿只读取两格整段口述。

第6步 · 补上开头和结尾

让整篇文章有方向

先有两段正文，再写开头和结尾。这里不提供天安门的完整范句。

开头只完成两件事

告诉读者推荐哪里；让读者知道你最想介绍它的什么。

结尾只完成两件事

说清这里适合谁；留下一个你最想让读者记住的意思。

现在合上所有帮助，只看“开头、理由一、理由二、结尾”四个标题，把整篇作文完整说一遍。
